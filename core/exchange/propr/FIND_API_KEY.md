# How to Find Your API Key

## Step-by-Step:

1. Go to https://app.propr.xyz/settings
   (Direct link — click it now)

2. Look for "API Keys" section on the Settings page

3. Click "Generate API Key" button

4. Copy the key that starts with `pk_live_`

5. Send me the key (or paste it in the .env file)

## If You Don't See the Settings Page:
- Make sure you're logged in (check top right corner)
- Look for a gear icon (⚙️) or "Settings" in the navigation
- The API key section should be clearly visible

## Where to Paste It:
Once you have the key, send it to me and I'll update the .env file.

Example format: `pk_live_abc123def456ghi789...`
